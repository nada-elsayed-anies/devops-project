# 🚀 DevOps Project

A simple web application created to learn and practice **Git, CI/CD, automated testing, and deployment**.

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Node.js & npm
* Jest
* Git & GitHub
* GitHub Actions
* GitHub Pages
* Linting

## 🔄 CI/CD Pipeline

```text
Git Push
   ↓
GitHub
   ↓
GitHub Actions
   ↓
Install Dependencies
   ↓
Run Tests
   ↓
Deploy
   ↓
GitHub Pages 🌐
```

If the tests fail, the deployment is stopped.

## 🧪 Testing

Automated tests are written using **Jest** or **lint**.

Run tests locally:

```bash
npm test
npm.cmd run lint
```
